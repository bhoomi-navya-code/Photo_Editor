# 📷 Photo_Editor
A simple photo editing application made to lure Python and gui

## ⚙️ Technologies

* Python
* Tkinter / CustomTkinter
* Pillow (PIL)

## 📔 What does it do?

**Photo Editor** is a simple application that allows users to open and edit images.

It includes:
 
* 🖼️ Open images
* ✂️ Crop images
* 🔄 Rotate images
* 🌗 Adjust brightness
* 🎨 Apply basic filters
* 💾 Save edited images
* 🖥️ Graphical user interface

## 📚 What I Learned

While building this project, I learned:

* Working with images using Python
* Using the Pillow library
* Creating GUIs with Tkinter/CustomTkinter
* Handling buttons and user input
* Working with files and file paths
* Applying image transformations
* Connecting image-processing logic with a GUI
* Organizing a larger Python project
* Using classes and objects
* Managing application data and state
